# Responsiveness
## Purpose
Make pointer response, scrolling, and route entry smooth and snappy while preserving the current art direction and motion branding. The user authorized a pre-change checkpoint and bounded implementation on 2026-10-01. Lower resource counts are useful only when they improve the experience; they are not acceptance criteria.
## Constraints
Preserve live halftone, trails, physical route choreography, timings, typography, and decorative motion. Retain prepared DOM and compositor surfaces when that avoids cold entry. Do not trade background savings for a visible hitch when a section returns. Preserve reduced-motion behavior and destination-first transition handoff. Route choreography's existing visual QA remains separate.

## Candidate Mechanics
Cache heading proximity with an IntersectionObserver using a generous 1,500px band. Pointer frames keep the original easing but skip letter reads and repeated reactive publications for distant headings. Keep all markup, CSS animation, and compositor hints. On scroll, resize, or transition completion, synchronously recheck a distant heading before scheduling its update so a large jump does not wait for an observer notification.
## Rejected First Attempt
A synchronous parent-bound check on every pointer frame reduced distant letter reads and preserved visible transforms, but timings were mixed when headings were nearby. Those extra hot-path reads were removed. The initial patch and alternating browser runs remain in the ignored evidence directory; resource/call-count improvements alone were insufficient to keep it.

Whole-page timings remain noisy and mixed; this does not establish a general FPS or production speedup. Final desktop samples contain no intervals above 25ms. Phone touch and reduced-motion states match the baseline and retain zero letter reads.

## Same-Frame Renderer Batching
The second candidate snapshots geometry, border offsets, and opacity for every eligible live image before mutating any canvas or readiness class, then paints in the existing order in that same callback. Detached surfaces are cleaned up before measurement. This removes the renderer’s internal read-after-write cycle without a deferred paint, visibility teardown, shader change, or new scheduler. Controlled fixed-pose geometry and pixels are identical; startup/handoff/fallback/trail checks pass. The small renderer callback costs less in paired scroll runs, while overall frame rate already remains steady and whole-page timing gains are not established.
