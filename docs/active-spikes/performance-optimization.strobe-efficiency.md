Every original round has 103–136 warnings. The filter has zero in all six forward flights and 13 across two reverse flights (5 and 8); its other four round trips have none. The retained trace prefix includes the user-confirmed failing original guard. Between its forward activation and reverse settlement, the page renderer records 459 `TileManager::AssignGpuMemoryToTiles` events; 108 explicitly report `had_enough_memory_to_schedule_tiles_needed_now: false`. There are 531 `TileBasedLayerImpl::AppendQuads checkerboard` events. These corroborate missing render tiles internally. No synchronized film maps each event to a physical flash; checkerboard events can occur multiple times per frame/layer.

[Exact Chrome153 tile-manager source](https://chromium.googlesource.com/chromium/src/+/199a3a541d76237379e353b348e64045584db057/cc/tiles/tile_manager.cc#1025) emits this warning when a NOW-priority tile cannot fit after lower-priority resource eviction. Limits consider memory bytes and resource count. This means Chrome's tile scheduling budget cannot accommodate all needed work; it does **not** establish that the Mac has exhausted physical RAM. The sample does not expose the exact allocation limit or resource retention responsible.

Working explanation: eight changing trail surfaces create a tile/resource demand problem in the failing rendering configuration; changing the composition path with the reference filter largely suppresses those failures while increasing GPU work. S18's default→CA-disabled→default reversal remains complementary evidence of renderer dependence. Whether CA resource retention, allocation policy, scale/cadence or another interaction causes the budget failure is still a hypothesis. Missing tiles also need to be related to earlier whole-plane/title/panel loss before declaring the exact mechanism solved. The next causal investigation should target this budget/presentation connection rather than another prefetch patch or generic layer promotion. Do not increase a browser-wide budget or disable rendering features as a website fix.
