# `gendes-semplice.codex` Reference Notes

Reference inspected: `https://vanschneider.com/`

## Useful Signals

- Personal site as designed artifact, not neutral portfolio container.
- Framed world: the page feels like a deliberate object on a stage, with strong edges, dark ground, and high-contrast internal scenes.
- Taxonomic navigation: labels and groupings feel curated, editorial, and archive-like.
- Dark stage plus sharp red signal color.
- Dense media-led sections where images and videos do real compositional work.
- Mix of studio, archive, editorial, and product language.
- Large confident type paired with tiny index labels.
- Motion personality comes from media emphasis, contrast, and stage changes more than from cute microinteractions.

## Borrow Carefully

- Use the reference to justify bolder framing, darker ground, and stronger archive logic.
- Translate the red into a restrained proof/index accent.
- Let cards and slips feel like objects pinned to media, while preserving the existing featured-media transition hooks.
- Keep article reading surfaces more humane than the homepage stage.

## Avoid

- Literal HOVS identity motifs, mythology, marks, angels, crests, or copy tone.
- Exact color costume as the whole design.
- Proprietary font imitation.
- Page-builder density or inline style sprawl.
- Scroll-script dependence.
- Decorative effects that make static preview, keyboard navigation, or reduced motion worse.
