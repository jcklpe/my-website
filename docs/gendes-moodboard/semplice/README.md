# Semplice mood board — web reference

This design branch pulls from a **live website** rather than a collected image board.

## Primary reference

- **`https://vanschneider.com/`** — House of van Schneider / DESK Magazine.
  Tobias van Schneider's personal site, built on Semplice (the portfolio platform he created). The branch name `gendes-semplice` is the nod.

## What was read from it

- Bright, cool near-white gallery ground; near-black charcoal text.
- Deep saturated full-bleed color panels (navy, oxblood, burnt clay) as section / project set-pieces — color in slabs, not sprinkled accents.
- Big confident **upright** grotesque display type; ALL-CAPS tracked declarative statements ("I CREATE; THEREFORE I AM"); Title Case for project/article titles.
- Brand face is Maison Neue (Milieu Grotesque, paid) — substituted here with Clash Display (display) + Switzer (body), both free for commercial use via Fontshare. IBM Plex Mono kept for code/labels.
- Flat surfaces, minimal shadow, vertical-rule dividers, arrow `→` CTAs, generous vertical rhythm alternating white and color bands.

The full translation lives in `docs/gendes-brief.md`.

## Note

No local image assets are stored here — the reference is the live site. Mood-board media is Git-ignored by convention; this README is intentionally tracked context for the branch.
