# Nature mood board — notes

Branch: `gendes-nature.cc` · Direction: **Glasshouse Nocturne** (see `docs/gendes-brief.md`).

## Image clusters

1. **Wet, tactile, real forest** — moss/clover/fern/granite, PNW + Dartmoor (`41dbc…`, `a5553…`, `f753c…`, `56f56…` glowing hollow). Used as imagery/texture register, not UI surface.
2. **Flat Eyvind-Earle jewel nocturne** — crescent moon, hard-edged jewel canopies, lone vermilion tree (`2d5dc…`, `d99d5…`, `52ae5…`, `f1b55…`, `7ff23…` folk pointillist). The lead surface treatment.
3. **Fantastical botanical specimen plate** — coral-tree, fine ink, gradient ground (`07445…`). The herbarium "specimen label" voice + generative ornament.
4. **Green glass / caustics / translucency** — glass-block walls, caustic water-light, lotus from below (`ed43d…`, `ac1e3…`, `86bbc…`). The material language: cards, media frames, the lit vitrine.
5. **Surreal intervention** — mirrored monolith in redwoods (`18016…`). Composition principle: clean structured column inside a lush world = reading vitrine + glazing-bar grid.

## How it maps to UI

- Night = the world (green-black ground). Light = where you read (luminous frosted-green vitrine).
- One hot accent: vermilion. Small jewel set (gold/cobalt/orchid/moss) for ornament glints only.
- Material: tinted green glass with refractive edges, glazing-bar mullions, caustic shimmer.
- Type: Bodoni Moda (jewel-cut Didone display) + Hanken Grotesk (body). No iridescence, no Fraunces — stay distinct from sibling branches.

Mood-board images are local/git-ignored; this notes file is intentionally tracked.
