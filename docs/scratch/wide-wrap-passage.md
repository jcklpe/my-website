# Wide Wrap Passage
Consider a Gutenberg Group style or variation named **Wide Wrap Passage** (`is-style-wide-wrap-passage`). A wide content track would let a floated image grow beyond the normal article-column float while keeping prose in one flowing body that wraps alongside and below it, rather than a fixed two-column/media-text layout.

The editor should approximate the public result. Choosing the wider prose/image frame is a separate editorial layout decision; normal image resizing must not activate it. This was outside the image-resizing spike.
